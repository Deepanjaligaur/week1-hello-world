
# Week 1 - Hello World

## About the Project
This is my first Node.js project, created as part of the Week 1 Setup & Git Workflow task.

## Requirements
- Node.js
- npm
- Git

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run `npm install` if required.
4. Run `npm start`.

Welcome to my Week 1 project.
